# Enhancement roadmap

## Next release

- Add email verification, password recovery, account deletion, and active-session management.
- Add application history so users can reopen prior concept submissions from the workspace.
- Add upload progress, retry, cancellation, retention controls, and malware scanning.
- Add automated end-to-end coverage for account, application, registry, document, PDF, and submission flows.
- Add registry freshness monitoring and a visible stale-data state when the daily mirror fails.
- Add keyboard and screen-reader testing across the complete application journey.

## Pilot readiness

- Validate every route and supporting-document rule with FAA subject-matter experts.
- Add explicit revision tracking for FAA source documents and rule changes.
- Add structured office and designee discovery based on location and application type.
- Add collaborative applicant and representative roles with a complete audit history.
- Add secure records retention, export, deletion, incident response, and operational monitoring.
- Conduct privacy, security, accessibility, and legal review before accepting real applicant data.

## Future integration

- Connect to an authorized FAA submission channel if one becomes available and is approved.
- Support reusable aircraft profiles while preserving field-level confirmation for every application.
- Provide status updates, requests for additional information, and inspector communications through authenticated integrations.
- Add reporting on incomplete applications, common document gaps, and processing milestones without exposing applicant data.
